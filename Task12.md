# Task 12

## Что изменили

В проекте реализовали персонализированное хранение памяти по `userId`.

### 1. Выбор пользователя при запуске

- при старте приложение запрашивает `userId`;
- `userId` валидируется;
- после этого зависимости и пути к файлам инициализируются для конкретного пользователя.

### 2. Контекст пользователя

Файлы из `context_source` теперь подставляются из директории пользователя:

- `context_source/users/<userId>/profile.md`
- `context_source/users/<userId>/task_context.md`

Это позволяет держать отдельный профиль и отдельный рабочий контекст для каждого пользователя.

### 3. История диалога

История тоже стала персональной и хранится отдельно для каждого пользователя:

- `generated/users/<userId>/history.json`

### 4. Ограничения пользователя

В `profile.md` добавлена новая секция:

- `## 3. Ограничения пользователя`

Эта секция может редактироваться агентом и используется для фиксации ограничений, запретов и устойчивых рамок, которые нужно учитывать в следующих диалогах.

## Итог

Теперь у каждого пользователя свои:

- профиль;
- рабочий контекст задачи;
- история сообщений.

Дополнительно в долговременный профиль вынесены редактируемые ограничения пользователя.
